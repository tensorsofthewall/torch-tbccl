# torch-tbccl 0.3.1 validation

```{warning}
**This is not a certification.** torch-tbccl 0.3.1 is a security-maintenance patch release of 0.3.0 (TBCCL C ABI 1, wire protocol 4). The adapter source is unchanged apart from the version string, so the runtime and physical evidence of 0.3.0 stands and is not repeated; this page records what is specific to 0.3.1.
```

## What changed

The wheels are rebuilt against TBCCL 0.7.1 (the library sources are identical to 0.7.0) in a patched build environment after the October 2026 emSign CA removal; see the changelog and `SECURITY.md`. This is not a vulnerability fix: none of the 0.3.0 wheels contains a CA bundle or performs TLS.

## Why no physical requalification

The maintenance policy treats a CI, documentation or release-metadata change as needing no physical run. The adapter sources and the framework pin are unchanged, TBCCL 0.7.1 differs from 0.7.0 only in its build environment, and the CI clean-install jobs install the built wheels and run the test suites. The built wheels are compared with the 0.3.0 wheels in the maintainers' release record.

## Release artifacts

The CI-built wheels, checksums, SBOMs and attestations are verified from the outside with `tools/verify_public_release.py --download` after publication; the result is recorded in the release notes of the GitHub release.
